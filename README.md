# 7K Rubiez

เว็บคำนวณฟาร์มรูบี้ภาษาไทย ใช้ HTML/CSS/JavaScript เปิดใช้งานได้ทันที ไม่มีขั้นตอน build และไม่มีบริการภายนอกสำหรับคำนวณ

## ตัวเลือก

- ปกติ: 5 ตัว / 6 กุญแจต่อรอบ / รับโบนัสทุก 160 รอบ
- ฝันร้าย: 8 ตัว / 12 กุญแจต่อรอบ / รับโบนัสทุก 80 รอบ
- บัฟรายเดือน: EXP +10%
- พาสกุญแจ: ฟื้นฟูจากทุก 3 นาที (480 ดอก/วัน) เป็นทุก 2 นาที (720 ดอก/วัน)
- จำนวนวันที่ฟาร์ม กล่องซื้อและฟรี EXP และของรางวัลปรับได้
- บันทึกค่าล่าสุดใน localStorage ของเบราว์เซอร์ มีปุ่มคืนค่าเริ่มต้น

## คำนวณ

ข้อมูลเริ่มต้นมาจากเครื่องคำนวณฟาร์มรูบี้.xlsx และเงื่อนไขโหมด/พาสที่ผู้ใช้ระบุ

ซื้อ 120 + ฟรี 1 กล่องต่อวัน กุญแจ 60 ดอกต่อกล่อง กุญแจฟรีอื่น 110 ดอกต่อวัน โบนัส 20 ดอก EXP พื้นฐาน 1,200 เป้าหมาย 12,500 และ 20 รูบี้ต่อตัวเมื่อตัน

ราคาซื้อกล่องต่อวัน:

```text
min(ซื้อ,20) × 50
+ min(max(ซื้อ−20,0),50) × 80
+ max(ซื้อ−70,0) × 100
```

รอบพื้นฐาน = floor(กุญแจรวม / กุญแจต่อรอบ)
โบนัส = floor(รอบพื้นฐาน / เกณฑ์ของโหมด) × กุญแจโบนัส
รอบทั้งหมด = floor((กุญแจรวม + โบนัส) / กุญแจต่อรอบ)
รอบจนตัน = ceil(EXP เป้าหมาย / EXP จริงต่อรอบ)
ตัวตัน = floor(รอบทั้งหมด × ตัวต่อรอบ / รอบจนตัน)
กำไรสุทธิ = ตัวตัน × รูบี้ต่อตัว − ต้นทุนซื้อกล่องทั้งหมด

โบนัสคิดครั้งเดียวจากรอบพื้นฐานตาม Excel B29–B30 ไม่ทบโบนัสจากรอบเพิ่ม และเกณฑ์โบนัสสะสมตลอดช่วงฟาร์ม กุญแจฟื้นฟูคิดครบ 24 ชั่วโมง ไม่มีช่วงกุญแจเต็มจนหยุดฟื้นฟู ตัวตันใช้ความคืบหน้ารวมตาม Excel B35–B36 ไม่บังคับให้จบทั้งชุดพร้อมกัน ราคาแพ็กเกจ/พาสไม่รวมในกำไรหน่วยรูบี้

แก้สูตร B21 ที่บังคับขั้นต่ำ 50 กล่องให้ตรงขั้นราคาและแยกกล่องฟรี แก้ B44–B48 ที่อ้างอิงผิดเป็นการเลือกผลที่ตรงกับบัฟ และแสดงผลรวมตลอดช่วงแทนป้าย “ต่อวัน” ที่ไม่ตรงสูตรเดิม

## ใช้งานและทดสอบ

เปิด `index.html` ในเบราว์เซอร์ หรือใช้ static HTTP server

```sh
python -m http.server 8765
node --test calculator.test.js
```

## GitHub Pages

ใน repository ไปที่ **Settings → Pages → Build and deployment**
เลือก **Deploy from a branch** จาก branch `main` และโฟลเดอร์ `/(root)` แล้ว Save
ไฟล์ `index.html` ต้องอยู่ที่ root ของ branch ที่เลือก
